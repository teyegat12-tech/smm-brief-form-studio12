# Анкета SMM-брифа

Публичная форма для первичного опроса заказчика.

- GitHub Pages публикует `index.html`.
- Vercel публикует защищённый обработчик `api/send-brief.js`.
- Telegram-токен и ID чата хранятся только в переменных окружения Vercel.

## Переменные окружения Vercel

- `TELEGRAM_BOT_TOKEN`
- `TELEGRAM_CHAT_ID`
- `ALLOWED_ORIGIN=https://teyegat12-tech.github.io/smm-brief-form-studio12`
